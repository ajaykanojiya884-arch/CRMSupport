Datastraw Operations CRM Dashboard

Project overview:
This project is a production-style operational support CRM dashboard designed for internal support and operations teams. It includes authentication, ticket management, analytics, AI-assisted support workflows, and a modern dashboard interface for managing customer service operations.

Core features implemented:
- OTP-based email authentication flow with secure verification and session handling
- Ticket creation, listing, filtering, search, and detail updates
- Support ticket status tracking (Open, In Progress, Closed)
- Dashboard overview with operational KPIs and performance charts
- AI-assisted support functions for ticket summarization, classification, suggested response, and next-action guidance
- Modern responsive UI built with React, Vite, TypeScript, and Tailwind CSS
- FastAPI backend with SQLAlchemy ORM and SQLite-ready local configuration

Technology stack:
- Frontend: React, TypeScript, Vite, Tailwind CSS, React Router
- Backend: FastAPI, SQLAlchemy, Pydantic, Python
- Database: SQLite for local development, MySQL-ready project configuration
- Authentication: OTP email verification flow
- AI hooks: extensible AI service layer for future provider integration

Project purpose:
The application simulates a real internal operations and support portal used by customer support teams to monitor workload, investigate cases, and improve response quality with operational visibility and AI support.

Why this project stands out:
- It is not a basic CRUD demo; it is structured like a professional operations dashboard
- It includes role-style business workflow thinking, dashboard analytics, and operational UX
- It demonstrates integration between backend APIs, frontend UI, and data-driven features
- It is organized for extension into real-world deployment scenarios

How to run locally:
1. Open terminal in backend folder
2. Activate virtual environment:
   D:\mini\.venv\Scripts\Activate.ps1
3. Start backend server:
   cd D:\mini\backend
   python main.py
4. Open another terminal in frontend folder
5. Start frontend:
   cd D:\mini\frontend
   npm install
   npm run dev
6. Open the browser and access the app
